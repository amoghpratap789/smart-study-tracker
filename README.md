# Smart Study & Sleep Tracker

## 📌 Problem
Students often struggle with poor sleep, stress, and low productivity.

## 💡 Solution
This project analyzes:
- Sleep hours
- Study hours
- Stress level

And provides:
- Productivity score
- Health suggestions

## ⚙️ How to Run

1. Install Python
2. Run:
   python main.py

## 📊 Features
- Productivity calculation
- Smart suggestions
- Easy to use CLI

## 🧠 Learning Outcomes
- Python basics
- Decision making (if-else)
- Problem solving
